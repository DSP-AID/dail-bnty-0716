# Dataset card — `data/passages_clean.csv.gz`

**Source:** Kaggle dataset [`prvsiyan/extended-name-that-llm-dataset`](https://www.kaggle.com/datasets/prvsiyan/extended-name-that-llm-dataset), file `passages_clean.csv`, version 13 line (dataset card dated 2026-11-11). Public, **CC BY 4.0** (the `train_regen` *prompt texts* stay CC BY-SA 4.0 with attribution to `pjmathematician/ntl-train-prompts-reconstructed`).

**Why this corpus:** every passage is one answer to one prompt, and prompts are issued as *blocks* — the same prompt answered by every model once. Holding the topic fixed and letting only the author vary is exactly the setting a prompt-grouped OOF check needs, and it is what makes TRACE's within-group ranks well defined. It is also the public dataset the house's V-series (Name That LLM, 18-class balanced accuracy) trains and validates against.

**What was shipped (no other change):** all 5,070 clean rows, columns cut to the nine below, written back as gzip. Nothing was filtered, resampled or relabelled.

**Shipped columns** (full descriptions in `column_dictionary_shipped_columns.csv`, taken verbatim from the dataset's own `column_dictionary.csv`): `id`, `split`, `prompt_id`, `source_prompt_id`, `model`, `text`, `n_words`, `target_words`, `provider_route`.

**Caveats, stated honestly:**
- All text is AI-generated by the dataset host through provider APIs; it is *not* the Kaggle competition's own train passages (the host's prompts are not published, so `train_regen` rows use community-reconstructed prompt texts). Scores here therefore describe this corpus, not the private leaderboard.
- Generation protocol differs slightly per split (`new`/`new2` with per-generation word targets, `proxy_v1` through the Kaggle Benchmarks proxy, `train_regen` on reconstructed prompts). Folds mix splits, so a split-specific protocol cue can leak *within* a training fold but never across folds (blocks are kept whole and every split appears in both sides).
- Provider API terms restrict using outputs to train competing commercial models; this repo is a reproduction/verification harness, and the dataset card asks downstream users to check those terms.
